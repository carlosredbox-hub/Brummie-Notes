# Fontes de documentos

Open Sans para conteúdo e Cormorant Garamond para capas e títulos, licenciadas sob SIL Open Font License 1.1. As respectivas licenças estão neste diretório.

Fontes obtidas do repositório oficial Google Fonts (`ofl/opensans` e `ofl/cormorantgaramond`) via HTTPS. Instâncias estáticas de pesos400/700 e estilos normal/itálico, geradas com fontTools; subconjunto Latin Extended, pontuação, euro e seta. São incorporadas localmente no PDF e no HTML do guia, sem buscar fontes na internet.
