# Exemplos completos do app

Fotos do PDF realmente exportado, com dados fictícios e imagens ilustrativas. Os cinco painéis mostram todos os 15 formatos e todas as páginas no tema Clássico azul; o sexto compara quatro temas. O conjunto entregue ao usuário inclui 60 PDFs renderizados em 175 páginas: cada formato nos quatro temas.

A logo branca é exclusiva do app. PDFs usam as marcas coloridas anteriores; Lines tem asset de rodapé separado do ícone do aplicativo. A composição lateral foi retirada; valores não são colocados automaticamente na capa.
