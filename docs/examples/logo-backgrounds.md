# Logos: preservar o original no fundo certo

Mesmo arquivo de logo com fundo branco opaco: preservado no documento claro, limpo na composição sobre azul/escuro. A marca e as cores são mantidas; logos já transparentes não são alteradas. Esta regra não se aplica às fotografias.
